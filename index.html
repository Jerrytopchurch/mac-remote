Mac Remote 隱私權政策

最後更新：2026 年 11 月 17 日　·　適用於 Mac Remote（iPhone）、Mac Remote（Mac）與 Mac Remote Host

我們不收集任何資料

Mac Remote 沒有帳號、沒有雲端伺服器，也不含任何分析、廣告或第三方追蹤元件。開發者收不到、也看不到你的任何資料。

資料只在你的裝置之間傳送

Mac 的畫面、你輸入的滑鼠與鍵盤操作、以及同步的剪貼簿文字，只會在你的 iPhone（或控制端 Mac）與被控端 Mac 之間直接傳送，不會經過任何第三方伺服器。連線使用存取碼驗證，並以 TLS 全程加密。

儲存在裝置上的資料

App 只在你的裝置上保存：你新增的被控端名稱與位址、畫質等偏好設定，以及存放在系統鑰匙圈裡的存取碼。刪除 App 即可移除這些資料。

權限

區域網路：用來在你的 Wi-Fi 上尋找並連線到你的 Mac。
剪貼簿：只有在你連線時，才會把 Mac 上複製的文字放進 iPhone 剪貼簿；只有在你按下「把 iPhone 剪貼簿送到 Mac」時，才會讀取 iPhone 的剪貼簿。
螢幕錄製、輔助使用（僅 Mac Remote Host）：用來擷取畫面並執行你從控制端送出的滑鼠鍵盤操作。

兒童隱私

本 App 不收集任何人的個人資料，包含兒童。

政策變更

若本政策有所變更，會更新本頁並修改上方的日期。

支援

連不上被控端？

請確認：Mac 沒有睡眠、Mac Remote Host 正在執行、iPhone 與 Mac 在同一個 Wi-Fi、iPhone 的「設定 › 隱私權與安全性 › 區域網路」已允許 Mac Remote、存取碼輸入正確。不在同一個網路時，兩邊都需要連上 Tailscale 等 VPN，並手動輸入 Mac 的位址。

聯絡方式

問題與建議請到 GitHub 問題回報 留言。
